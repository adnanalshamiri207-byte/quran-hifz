# رفيق الحفظ - بناء APK من الهاتف

هذا المشروع مجهز للبناء السحابي عبر GitHub Actions، ولا يحتاج Android Studio على هاتفك.

## من الهاتف
1. أنشئ حساب GitHub إن لم يكن لديك.
2. أنشئ Repository جديداً.
3. ارفع **محتويات هذا المجلد** إلى المستودع، وليس ملف ZIP كملف واحد.
4. افتح تبويب Actions.
5. اختر Build Quran Hifz APK ثم Run workflow.
6. بعد نجاح البناء افتح آخر تشغيل، وانزل إلى Artifacts.
7. حمّل QuranHifz-APK، ثم فك ملف artifact ZIP وستجد app-debug.apk.
8. ثبّت APK على Android. قد تحتاج السماح بالتثبيت من هذا المصدر.

ملاحظة: واجهة التطبيق موجودة داخل APK ولا تحتاج HTTPS لفتحها. النص القرآني في نسخة V8 الحالية يُجلب من api.alquran.cloud عند الحاجة، لذلك يلزم الإنترنت لأول تحميل للسور غير المخزنة.
